## 一、开场与个人学术背景相关提问

1. 你科研方面的研究成果是怎么样的呀？
2. 这篇 IEEE Trans 的论文准备了多长时间？
3. 会议论文投的是什么会呢？
4. 你们的毕业要求是什么呢？
5. 按你刚才的信息来看，其实主要是寄希望会议的那篇论文可以中，是吧？
6. 所以学硕的一篇发表论文是硬标准，对吗？
7. 你们实验室主要是做啥方向的？有多少研究方向？
8. 实验室的规模大概怎么样？
9. 你目前的研究是偏工程还是偏理论多一些？就是你所跟的导师和导师的研究方向。
10. 那你的工程能力主要是怎么来的？
11. 如果你投了 Trans，那应该也是偏理论的研究，那你为什么想找一个工程方向的工作呢？
12. 当年高考是哪个省份的？排名大概怎么样？

## 二、工程基础、项目与 Java 技术相关提问

1. 那你的这些工程经验基本是自学，对吧？
2. 这些编程知识是硕士期间开始学，还是本科期间就有相关学习？
3. 本科或硕士期间有参加一些编程比赛什么的吗？
4. 一些创新创业项目这种东西有参与吗？
5. 我们来聊一下为什么选这两个项目？网上应该有很多项目，为什么不选其他项目？
6. 其他语言熟悉吗？或者有了解吗？
7. 那当时为什么不选 Python 的 LangChain，反而选了 Spring AI？
8. 那我们来聊一下 Java 这一块，你的意思是硕士主要是自学的 Java，对吧？
9. 那我们来聊聊你的框架，你主要学了哪些框架？
10. 所以你的项目基本上是单体的，是吗？
11. 分布式相关的一些东西有了解过吗？
12. 我看你简历里写到了 Redis 的分布式锁，那分布式锁主要用来解决啥问题的呢？

## 三、AI 相关技术、Agent 与工具实践提问

1. 那我们聊聊你 AI 相关的部分，你是有用一些 AI 的编程工具，是吧？
2. 主要用哪一些？简单聊聊你的理解和实践。
3. 你刚才提到的计划，如果你跟它确认后它去执行了，结果还是不符合预期，你接下来会怎么做？
4. 有具体的场景吗？比如说你在什么样的场景下，用基于测试驱动来进行代码编写的？
5. 那我们再聊一下你第一个项目里提到的 react 模式，这具体是个什么东西呢？
6. 那除了 Spring AI Alibaba 框架，你对其他的 Agent 框架有了解过吗？不同框架基于 react 模式的实现，差异和共性主要是什么？
7. 你刚才提到 Agent 里会有循环执行，那循环的终止条件是什么呀？
8. 最大循环轮次一般怎么设计的？
9. 那你现在单次的执行大概需要耗费多长时间呢？
10. 这里面还提到你用了 LLM 做相关性的评分，这个你是怎么做的？讲一下具体细节。
11. 那我们聊一下你第四个功能点 AIOps，讲一下它整体的设计思路、核心模块，以及这些模块解决了什么问题。
12. 能给我举一个具体的测试案例吗？比如什么样的告警，你这套链路是能跑通的。
13. 这里面你提到了 MCP，MCP 在你的项目中是怎么用的？用来干什么的？
14. 那 MCP 跟你的大模型、Agent Loop 是怎么结合起来的？能讲一下它的执行过程吗？
15. skill 是个什么东西？
16. 除了刚才的 MCP、skill 这些名词，近几个月在 AI CODING 或者大模型相关的领域，你脑子里还有哪些相关词汇？可以简单介绍一下。
17. Claude 和 Hermes 是用来干嘛的？
18. 如果我也想要一个你说的这种自动搜论文、做综述汇报的工具，在我的电脑上，你觉得应该怎么帮我实现？

## 四、AI CODING 编程题（实现AI审核评论并自动删除或人工介入）相关提问

1. 那我们聊一下你的 AI CODING 那道题目，你切到你的 AI CODING 项目那个地方。
2. 讲一讲你的这个项目吧。
3. 代码看过吗？
4. AI 生成的这些代码，你一般怎么 review 的？
5. 好的，那第三个问题（edge case）你怎么解答的？

## 五、职业规划、实习与 Offer 情况提问

1. 我们来聊聊你当前的 offer 情况，还有各方面的进度，简单聊聊。
2. 你目前的 offer 情况、面试进度怎么样？
3. 已经拿到的 offer 是哪个公司的？
4. 华为的岗位是在哪个城市？
5. 你未来的规划是啥？比如城市选择，你刚提到是四川人，对未来工作城市的规划，目前有什么想法？
6. 家人对于你未来长期职业的所在城市，有什么样的建议吗？
7. 你这边可以实习的时间是怎么样的呢？
8. 暑假结束大概到什么时候？
9. 我们再聊回专业相关，我看你学的课程大多是机器学习、数据挖掘、强化学习、神经网络，没提到计算机网络、线性代数等基础课，你觉得你学的这些课程，和你目前了解的大模型、Agent 研发，有什么样的关联？在你的学习中，哪些地方有促进作用，甚至是背道而驰、影响你学习的？聊一下你所学的专业，和你未来想从事的大模型、编程相关工作，之间的关联关系到底是什么。
10. 同一个实验室和同一个宿舍的同学，目前的 offer 情况是怎样的？
11. 那存不存在你找到了某家公司的实习，但是导师不放人的情况？
12. 所以你最早可实习的时间大概在 5 月中下旬，对吗？
